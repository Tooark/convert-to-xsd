# Release Notes v0.1.0

Data de lançamento: 26/04/2026

## Descrição da release

Esta release estabelece a base do projeto, que converte JSON plano em estrutura JSON aninhada e gera arquivos XML e XSD de forma automática.

Escopo funcional do projeto nesta release:

- Conversão de chaves em formato pontuado para estrutura aninhada.
- Geração de arquivos de saída no mesmo diretório do arquivo de entrada.
- Suporte a saídas JSON, XML, XSD e XSD compatível com SAP.
- Execução via script Python e também via comando de linha (entry-point).
- Processamento de arquivos individuais ou diretórios com múltiplos arquivos de entrada.

## Impacto esperado

- Atualização da biblioteca de manipulação XML para versão mais recente.
- Potenciais melhorias de compatibilidade, estabilidade e correção de bugs da dependência.
- Recomendado validar fluxos de geração e parse de XML/XSD após a atualização.
